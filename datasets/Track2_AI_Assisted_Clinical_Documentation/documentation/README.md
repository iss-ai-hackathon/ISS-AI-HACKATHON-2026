# Track 2: AI-Assisted Clinical Documentation

## Overview

Welcome to **Track 2: AI-Assisted Clinical Documentation** of the **ISS 2026 AI Hackathon**.

This track focuses on the application of Artificial Intelligence and Natural Language Processing (NLP) to automate clinical documentation from doctor–patient conversations.

Participants will work with **NaClinDoc-500 (Nigeria Clinical Documentation Benchmark)**, a synthetic benchmark dataset designed to support the development of clinical documentation and healthcare NLP solutions.

---

## Challenge Statement

Develop an AI solution capable of converting unstructured doctor–patient consultation transcripts into structured clinical documentation.

Possible tasks include:

* SOAP Note Generation
* Clinical Summarization
* Diagnosis Prediction
* ICD-10 Coding
* Clinical Information Extraction

---

## Dataset

NaClinDoc-500 contains:

* Consultation transcripts
* Patient information
* Encounter information
* Structured annotations
* SOAP notes
* ICD-10 diagnosis codes
* Investigation recommendations
* Treatment plans

## Suggested Workflow

1. Explore the dataset and annotation schema.
2. Preprocess consultation transcripts.
3. Build or fine-tune an NLP model.
4. Generate structured clinical documentation.
5. Evaluate model performance.
6. Demonstrate clinical usefulness.
